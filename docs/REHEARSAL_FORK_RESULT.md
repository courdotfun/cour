1. **EIP-170**: the §2.3 PositionManager/Permit2 code pushed COURFactory to 26,448 B (> 24,576). Local and
   fork *tests* don't enforce the size limit; the anvil *deploy* does. Fixed by the delegatecalled
   `GraduationImpl` (factory → 21,264 B).
2. **Tiny-pool buyback sizing**: on the cheap test-param pool, the full `buybackOwed` exceeded the
   2%-of-reserve cap; the smoke script now caps the buyback. (The guard itself is correct.)
