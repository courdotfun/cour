# Visual diff — v8 design vs ported app

Snapshots generated by `app/test/visual.mjs` (Playwright). For each ported view
(home / token / create) at **3 themes** (classic/cartoon/light) × **2 viewports**
(desktop 1440, mobile 390):

- `app/{desktop,mobile}/<view>-<theme>.png` — the ported Next.js app (real data).
- `v8/{desktop,mobile}/<view>-<theme>.png` — `design/cour-v8.html` (demo data).

Regenerate:
```bash
cd app && pnpm build && pnpm start -p 3010 &   # then:
APP_URL=http://127.0.0.1:3010 TOKEN=<a real token address> node test/visual.mjs
```

## Expected differences (per spec §5)
Only two kinds of difference are allowed between `app/*` and `v8/*`:
1. **§4 changes** — Pools/LP "earn fees" → informational; Stock Reserve card removed;
   Limit order "Coming soon"; Oink Collection "Coming soon"; pay with ETH/stock.
2. **Data** — the app shows REAL on-chain/indexer data (e.g. the `$CSMOKE` token,
   real market cap, empty states where there is nothing yet); v8 shows demo tokens
   (QCAT/GIGA/NOVA/…), fake news, fake leaderboards.

Layout, spacing, colours, typography, promo/orbit animation and theme behaviour are
driven by the same `public/v8.css` (extracted verbatim), so structural rendering
matches. An automated per-pixel delta score (ignoring the data regions) is a
follow-up (task 10).
