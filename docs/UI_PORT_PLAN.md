## Per-view port method (keeps pixel-identity)
The v8 body markup is **generated by imperative JS** (render functions emit DOM
strings), so porting = reimplementing those render functions as React using the
**same class names** (already in `public/v8.css`). For each view:
1. Identify its render function(s) + section ids in `design/cour-v8.html`.
2. Recreate the markup as a React component with identical classes/structure.
3. Replace demo data with real data (indexer via `/api/ix/*` or server components;
   chain via `app/lib/features/*`). No `Math.random` in data — cosmetic only.
4. Port interactivity (theme, Oink, tabs, modals) into `app/lib/*` TS modules +
   React state; keep animations/classes identical.
5. Visual-diff that view (§5) at 3 themes × 2 viewports; diff must be data/§4 only.
