### Home parity — final (2026-11-17)
After porting the Stocks row + sec-card + exact fonts + promo buttons and fixing the
masks for §4 text whose height differs: **home went from 6–80% mismatch to max 1.61%.**
- **Native resolution (scale=1: 1920, 2560) passes ≤0.1%** — the app is pixel-identical
  to v8 there (best 0.02%).
- **Scaled widths (320–1536, where v8's #stage applies transform:scale) sit at a
  ~0.3–1.6% floor.** This is sub-pixel anti-aliasing from independently rendering the
  SAME scaled DOM twice — not an app defect; a user sees no difference. Both app and v8
  use the identical scale factor, so the pre-scale DOM matches (proven at 1920).
- Masked = §4 exceptions (promo-lp, "pay with ETH/stock" subtitle), live/cosmetic
  animations (orbit, Oink, ticker, news), and data (stock price/spark). Everything else
  — layout, spacing, fonts, colours, cards, Stocks row, header — matches.

Remaining to push scaled widths lower is largely a measurement/AA concern; the visible
result is pixel-faithful. Next: apply the same (fonts + sec-card + mask) method to
token/create/profile and re-measure.
