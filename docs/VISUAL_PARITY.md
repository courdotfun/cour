## Status

A control test (`app/test/control.mjs`, each source rendered twice under the gate's masks and diffed against itself) measured the renderer floor at **≤0.03%** for both app and v8 at every scaled width/dpr. So any residual is a **real app-vs-v8 DOM/CSS difference** (magnified when v8's `#stage` applies `transform:scale`), not anti-aliasing noise — and the gate is achievable by fixing the app.

Current worst: pre-scale 0.109% (gate 0.1%), scaled 0.109% (gate 0.5%).

`STATUS: ALL PASS` is intentionally NOT written — views still missing from the matrix: create, profile, user, wallet, scan, pools, collection, stock. It is emitted only when every required view (home, token, create, profile, user, wallet, scan, pools, collection, stock) passes both gates, and a human has confirmed the diff images show no shifted/missing element (the %-number alone is not sufficient for the secondary gate).
